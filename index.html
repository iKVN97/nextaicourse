02Module 01 — Control AI

One prompt. Every module builds on it.

This is the actual prompt you'll use throughout the course. Copy it. Use it today.

Context→ Goal→ Input→ Requirements→ Output
Master AI Task Prompt 
CONTEXT:
I am working on:
[describe the situation, project or problem]

GOAL:
The result I want is:
[describe the exact outcome]

INPUT:
Here is the information you should work with:
[paste information, notes, files, requirements or data]

REQUIREMENTS:
- Ask me questions first if essential information is missing.
- Do not invent facts, numbers, sources or requirements.
- Separate facts from assumptions where relevant.
- Work step by step internally, but give me a clear final result.
- Point out important risks, weaknesses or missing information.
- Prefer specific recommendations over generic advice.
- If there are several good approaches, compare them before recommending one.

CONSTRAINTS:
[budget, deadline, audience, tools, length, style or other limits]

OUTPUT:
Return the result as:
[exact desired format]

QUALITY CHECK:
Before giving me the final answer:
1. Check whether you answered the actual goal.
2. Check for unsupported assumptions.
3. Check whether anything important is missing.
4. Improve the result once before presenting it.
